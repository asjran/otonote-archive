# 活动曲冲榜搜索与加载交互（2026-10-19）

用户截图中的全卡库参考、最高分搜索已展开 17,544 个分支，当前分 17,852,260，上界仍高 93,435。小规模算分回归通过不能排除这种大卡库证明膨胀。

## 原因与修复

单谱冲榜直接划分成员与留影的配对，在近似等价配队之间反复展开分支。改为先以某张卡的选入／排除划分成员集合，再划分留影集合，最后比较配对。每对选入／排除子域互斥且完整覆盖父域；精确匹配保留必选卡、同角色互斥、留影容量与已有配对约束。原有上界、完整评分和最优证明条件不变，只有全部待检查域被排除后才宣布最优。收益计算继续使用原有搜索入口。

冲榜 Worker 同时复用收益的全力调度器，按 48 ms 时间片让出事件循环，避免每个短步骤都等待浏览器定时器。保留分段搜索、暂停和原 Worker 内续算。进度显示已检查／待检查分支和耗时，未知总量不显示百分比。

收益和冲榜共用 `calculation-live-updates.mjs`：进度每 250 ms 合并，第一份结果立即展示，后续中间结果每 750 ms 发布最新一份；结束、失败、暂停与条件失效清理过期更新。共用 DOM 排列逻辑，冲榜按队伍身份保留备选选择、卡组和技能播放节点，仅更新名次与证明标签。暂停后继续会立即恢复运行反馈。

可复算命令（本地规则、谱面文件作为参数，不提交个人卡库）：

```sh
node site/tests/benchmark-challenge-search.mjs \
  --rules RULES.json --chart CHART.json --output output/challenge-search.json
```

`--source-root DIR` 可对照另一份源码；`--account ACCOUNT.json` 可替换生成账号条件；`--max-evaluations N` 只用于有界对照，不会把未完成结果视为证明。输出保留输入指纹与源码哈希。
