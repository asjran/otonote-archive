# 2026-10-18 导航与工具任务切换修复

本次范围为修复并合入 `codex/release-2026-10-18`，不执行生产部署。

## 原因与修复

- 侧栏只恢复分组展开状态，没有恢复自身的滚动位置；直接进入工具页时选中项位于可视区域下方。冷启动入口和完整页面共用 `navigation-scroll`，恢复会话位置后只滚动侧栏以露出当前项；手机抽屉打开时再次定位，支持存储不可用的环境。
- 工具原型主题在 `body:has(.task-studio)` 上将侧栏缩为 192px，并把导航字号压到 12px／11px。移除对公共导航的覆盖，使用全站的 236px 和 13px／12px；工具字体限制在工具容器内。
- 页内任务标签把队伍、养成与发挥设置序列化为 HTTP 查询参数。线上真实浏览器读取同一歌曲计算页：短 URL 为 200，含合成设置的 16,099 字符 URL 为 520。三个任务标签改用 `#team-draft` 片段传递状态，只有区服参数进入 HTTP 请求；各工具显式读取片段，保留原查询参数链接兼容性，查询参数中的明确字段优先。
