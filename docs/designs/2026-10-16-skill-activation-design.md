# 技能发动顺序与紧凑详情

## 已确认范围

2026-10-16 用户选择：外显顺序链只显示头像和次序；保留随机性说明。技能小弹窗压缩留白、合并标题与养成提示，保留技能正文与等级。不重写配色、选卡弹窗、搜索或评分公式。

## 实现

- 推荐队伍结果旁直接显示最高分对应的五人发动顺序；平均分没有单一发动顺序，明确区分最高分顺序和平均分。
- 复用完整评分已有的 bestOrder；候选评估器透传轻量顺序与随机性元数据，不为摘要启动 Worker 或重新评分。发动时刻与技能条件留在原有按需回放中。
- 普通完整枚举称为最高分顺序；激奏及玩家随机场景称为最高分样本；指定回放与粗筛顺序单独标识。不将抽样最高分称为全局最佳。缺失或无效顺序不伪造。
- 保持五人顺序和站位含义分离：数字表示第几次发动，头像代表该次成员；无头像时以站位兜底，辅助文本保留成员身份。
- 技能小弹窗保留正文字号，合并标题/养成状态区，减少段间距与内边距。使用内容自然高度和视口边界，长文可滚动；关闭、Esc 和焦点返回沿用现有行为。
- 技能回放会被现有框架移动到独立对话框，因此用仅匹配 `.activation-body` 的局部样式收紧宽高与内部留白，不修改共享对话框逻辑。窄屏音轨独占一行，避免姓名和倒计时挤掉窗口图。
- 修正条件详情的跨表 ID 冲突：成员与留影效果 ID 不是全局唯一；按 ID 和已审计的效果类型匹配回放记录，避免成员加分记录误激活留影延长分支。评分和实际持续时间不变。

## 验证与整合

1. 使用真实评分结果核对外显顺序与最高分回放一致；覆盖随机样本、指定回放、缺失数据及平均分说明。
2. 验证顺序透传不改变最高、平均、最低分、120 种顺序计数及完整分布。
3. 真实浏览器查看桌面/窄屏顺序链、头像缺失、技能长文、弹窗键盘关闭，并记录前后面积。
4. 运行相关 Node 回归与 Astro 检查；已有 14 条 Astro 错误及全量 Node 6 个失败单独记录。

基线为发布分支 3861c0f；工作分支 codex/skill-activation。无推送、PR 或部署。

## 浏览器验收后的细化

用户要求减少弹窗的纵向占用，把播放进度与分数置顶，将外部详情入口并入顺序区，并进一步美化简图。

- 外部改为一条技能谱带：头像左上角标次序，保留轻量连接符；同区放小号「回放」按钮，取消独占一行的大折叠入口。窄屏按钮与标题同排，头像链在下一排完整展示。保持只有头像和次序，不增加外显时间或姓名。
- 回放顺序、综合力、累计分、最终分及短读数组成顶部播放台。播放台在弹窗内容区滚动时置顶，沿用现有关闭、缓存、Worker 和回放时钟。普通模式隐藏不适用的名次奖励读数。
- 合并重复标题，缩短说明；成员身份、留影、当前时刻、窗口数据和效果来源尽量同排。保留条件分支与覆盖音符详情。
