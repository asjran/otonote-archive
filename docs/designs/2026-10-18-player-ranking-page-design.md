# 玩家榜归档与页面调整方案

本轮需求：明确最终归档语义，补齐活动筛选和歌曲视觉信息，压缩玩家行，展示公开头像及名片，滚动自动加载。用户已明确活动颜色指加成属性颜色图标，页面沿用现有配色。

## 活动结束与最终记录

- 活动状态为“进行中、已结束、未开始”；时间不完整时显示“时间待确认”。依据当前区服已验证的活动配置计算，不用快照新鲜度判断活动是否结束。
- 活动结束后的首次调度重新读取一次官方榜单，完整校验后原子保存不可覆盖的最终记录；新活动出现时同时检查上期是否遗漏最终采集。失败保留待采集状态，按原有限重试和认证暂停规则处理，不将最后一次实时快照冒充最终榜。
- 将待结束活动的读取计划和来源证据持久保存，避免下一版公开投影移除旧活动后失去补采依据。每服独立队列，共用已有登录排队；每次处理量有界，失败不覆盖旧文件。
- 已有最终归档优先于同活动残留的 current 快照。最终记录显示“已结束 · 最终记录”和真实采集时间；后端与前端均不再按实时 TTL 显示“数据已过期”。进行中的旧快照仍保留过期提示。
- 后续公开配置中的所有活动均可选择；未开始的活动显示时间和暂无排名，不伪造榜单。历史归档继续保留，旧文件缺少新增资料时兼容展示。

## 页面与筛选

保留排行榜的列表结构，采用紧凑的音乐榜单布局。顶部以歌曲封面、曲名、活动名、加成属性颜色图标和状态组成歌曲区；沿用网站现有配色与字体，不根据乐队改变页面强调色。属性图标来自选中活动已验证的加成配置与网站属性资源映射，不凭歌曲或乐队猜颜色。歌曲封面缺失时显示统一音乐占位，不猜其他版本图片。

增加乐队筛选；活动关联乐队来自活动剧情及加成配置，合作活动可匹配多个乐队。活动选择项同时显示活动名和状态；筛选结果为空时明确提示。活动和歌曲选择保留可访问的键盘操作、明确选中态、长名称截断和移动端尺寸。选择歌曲时同步封面，切换活动时同步加成图标；链接继续保存区服、活动、榜单及歌曲选择。

玩家行使用“名次 / 头像与名字及名片 / 五人队伍 / 综合力与成绩 / 展开”结构。名片作为玩家资料区的轻量视觉信息，避免大面积装饰妨碍阅读；移动端调整为紧凑两行。展开内容保留突破、觉醒和确实提供的技能等级；经验不展示，缺失技能不创建标签或占位。既有分数异常提示保留。

## 头像和名片的数据边界

仅从榜单已返回的公开玩家资料中提取展示所需字段，不新增任意玩家资料查询。客户端静态字段证据与当前实服结构分别验证，未确认的嵌套字段不猜含义。

头像使用已确认的卡片或头像资源标识，与当前版本的公开资源目录映射；名片在确认其公开结构后展示可解析的缩略图或组成资源。外部图片只接受确认过的 HTTPS 来源和受限格式，不执行自定义 HTML/SVG。旧快照或上游没有资料时使用中性占位；不把队伍第一张卡冒充玩家头像，也不伪造个人名片。

## 自动分页

列表底部观察点进入视口后加载下一页，维持现有 50 条一页与快照摘要游标。不显示“再看 50 名”主操作；加载中禁止重复请求，切换区服、活动或歌曲时取消旧请求并清空游标。失败暂停自动重试，提供可点击的重试入口；快照变更提示刷新，不将两份快照混合。末页显示已加载全部记录；在不支持观察器的环境保留可操作的兼容入口。

## 验证与交付

回归覆盖最终归档不再过期、同活动 current 与 archive 的选择、活动切换补采、失败后待办保留及跨服隔离；前端覆盖活动状态、乐队过滤、缺失字段隐藏、自动分页并发和游标变化。使用现有候选构建入口生成完整代码候选，在桌面和移动尺寸验证封面、加成属性图标、玩家行、下拉框及滚动加载，再按现有发布流程验收线上网页、查询服务和采集器。保留旧代码、镜像和历史数据回滚，不修改不可覆盖的归档来补造新字段。
