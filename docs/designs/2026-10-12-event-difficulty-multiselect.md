# 计算器筛选多选

按用户确认的需求，将计算难度从单选改为多选，并统一扩展所有计算器同类筛选。活动收益的普通演出与后续挑战分别设置，选定范围在创建计算 Worker 前过滤，只计算所选难度的可用谱面；指定谱面继续只计算所选单张谱面。

界面沿用现有难度按钮，默认 EXPERT，可叠加 HARD、NORMAL、EASY。“全部”选中四种难度，点击单个已选按钮可取消，但保留至少一种。底层使用原生 multiple select 保存选择，按钮反映各自 aria-pressed 状态。乐队、属性、稀有度等普通筛选使用“全部”表示不限，最后一个具体选择取消时恢复不限。

范围包含活动收益的乐队/歌曲属性、队伍选曲与 AP 达档难度、所有计算器共用选歌器的乐队/难度、共用卡片选择器与卡库的属性/乐队/稀有度、配队候选的成员乐队/成员属性/留影属性，以及歌曲排行榜的乐队/难度。已支持多选的属性组件继续复用。角色、技能等其他筛选，以及具体谱面、模式、目标和排序保留现有含义。

同组筛选取并集，各组取交集。候选函数兼容原有单难度字符串与 all，新界面传递难度数组。两阶段的难度、最高等级及原有歌曲过滤条件各自组合。配队候选约束兼容旧数值与新整数数组，先过滤候选再校验必选卡与五位不同角色要求。条件变更停止旧任务并清空旧结果；必选难度不把空选择解释为全部。条件摘要显示完整选择，重置及动态筛选项重建保留有效选择或恢复不限。

验证覆盖 HARD＋EXPERT、活动歌曲及等级范围交集、两阶段独立候选、改变子集后任务失效、空范围拒绝、指定谱面和旧单选调用兼容；构建及浏览器检查确认实际按钮和 Worker 输入。

135 项相关回归测试通过，独立网页预览包构建成功。旧 `calculator-selection.test.mjs` 因当前干净检出缺少生成资料无法加载，新门禁使用已提交的公共规则与合成样例，不将生成资料补入源码。正式发布另走固定候选门禁及线上浏览器验收。
