# 发布功能记录、私有告警与热点读取

范围来自更新可靠性计划 F/G/H。告警仅展示于现有私有管理页和服务器日志；本地每两分钟采样已单独确认。专用 GitHub Token、外部生产调度、公共桶开放和线上压测均不在本批范围。

## 发布记录与兼容门禁

Actions 使用现有 R2 写入权限保存 `content/operations/{region}/latest.json`。Worker 不允许访问此命名空间；服务器沿用已有桶只读权限。回执只收录固定阶段状态、运行号、提交、结果和连续失败数，不保存步骤输出、SDK 错误、对象路径或凭据。运行号和 attempt 单调检查加 ETag CAS，防止旧完成覆盖新运行、重复计数；采样失败不改变生产门禁，回执缺失单独告警。

上传前检查双语目录、活动、技能和评分文件的摘要与版本绑定。必需目录缺失、跨版本/地区/语言混用、伪造空成功会拒绝上传；评分 `partial`/`unavailable` 是明确的可选降级，保持现有消费者拒绝不支持机制的行为。记录数量与能力状态，仍声明实机玩法未验证。未知解码与客户端继续走原有受审适配流程。

## 告警阈值

| 状态 | 初始策略 |
| --- | --- |
| 回执缺失、远端不可读、本机交付不可核对 | 持续 10 分钟 |
| 远端版本与已交付 HTML 不同 | 持续 10 分钟 |
| 运行失败 | 连续两次立即；单次持续 15 分钟 |
| 已完成探测结果陈旧 | 超过 60 分钟；不当作 15 分钟 SLA |
| 正在运行 | 六小时内不按探测陈旧报错；超过六小时告警 |
| 榜单采样陈旧 | 15 分钟未成功/样本异常，再持续 10 分钟 |
| 榜单暂停 | 持续 15 分钟 |
| 磁盘不足 | 低于配置的真实发布预算立即；不以 8 GiB 建议值告警 |

报告采用原子替换。相同告警持续只更新状态，日志仅写进入告警/恢复，保留最近 40 个转换。私有 API 再次白名单化，超过六分钟或未来时间异常返回不可用。既有本机交付状态与远端健康状态分别显示。

初始部署固定预算须与预渲染配置的同盘并发预算保持一致；预算变更时同步 `R2_HEALTH_BUDGET_BYTES`。采样自身停摆由页面六分钟失效和 systemd 失败状态暴露；本批没有外部推送或独立的监控系统。

## 热点映射缓存

在现有 8 MiB 控制对象缓存之外，为已认证的正向媒体映射增加独立 LRU，上限 4096 项且序列化键和值不超过 1 MiB。容量数字不等同 V8 堆内存；不缓存缺失/错误，不共享跨请求异步 I/O。映射仍由 release descriptor、manifest 和分片摘要认证；命中仍执行媒体 GET/HEAD 并核对 size/ETag。桶与 release/path 隔离；逻辑 URL、Live2D 相对路径、Range、mutable no-store 及 CDN 缓存语义不变。

隔离回放使用 16 个认证的约 600 KB 分片，覆盖总量超过原控制缓存的热点轮转；并发 1/4/12，预热后各 192 请求。比较控制读取、媒体读取、CPU 和时间；另测错误身份、访问边界和缓存容量。Node mock 结果不能称作 Cloudflare CPU/计费/高峰容量承诺。线上只做少量顺序抽查。

## 安装与回退

先合并并验证 CI。保存线上 Worker 版本、私有管理应用文件和本地服务配置；确认文件摘要与基线一致后再更新。健康采样使用已固定的预渲染 Python 镜像及桶只读凭据，输入挂载只读，仅状态目录可写。将 `deploy/admin/export_ranking_health.py` 安装到同一 libexec 目录，主机仅导出 status/paused/observedAt，避免降低原榜单 0600 文件权限或扩大容器能力。安装 `deploy/admin/run-update-health.sh` 和对应 service/timer，先手动采样验证，再启用 timer。应用仅替换 `node.py`、`update_health.py`、`static/admin.mjs` 并重启私有 node/admin，保留数据库、认证、其他服务和公开网站。

回退停止健康 timer 并恢复备份应用文件，旧交付采样继续工作。Worker 可恢复保存的版本。回执不参与业务指针，不需要删除；已有不可变内容与回退版本保留。新增功能门禁和工作流变化会改变生产指纹，后续首次双服生产按现有串行队列完整执行，不取消已有运行。
